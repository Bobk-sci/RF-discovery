# AI-Driven Optimization of Skyborne Base Station Architectures for Integrated 5G/6G Telecommunication Systems

*journal non renseigné — 2026*

## Résumé (texte d'origine)

<title>Abstract</title>  <p>The rapid evolution of 5G and emerging 6G telecommunication systems demands innovative network architectures capable of delivering reliable connectivity in remote and underserved regions. Skyborne base stations implemented through unmanned aerial vehicles (UAVs), high-altitude platforms (HAPs), and low-earth-orbit (LEO) satellites have emerged as promising solutions for extending network coverage and enhancing system flexibility. However, efficient integration of these aerial platforms with terrestrial infrastructure introduces significant challenges related to resource allocation, latency minimization, network management, and cybersecurity resilience. This study proposes an AI-driven telecommunication system architecture that integrates skyborne base stations with terrestrial and satellite networks to improve overall network performance. The framework incorporates machine learning (ML) and deep reinforcement learning (DRL) techniques for dynamic spectrum allocation, traffic management, and autonomous network optimization. The system design further integrates massive MIMO, ultra-dense network deployment, edge computing, blockchain-enabled security mechanisms, and self-organizing network (SON) capabilities to enhance scalability and operational efficiency. Extensive simulations and experimental evaluations were conducted under high-traffic and dynamic network conditions to assess system performance. The results demonstrate that the proposed architecture improves network capacity by 30%, reduces communication latency by 40%, enhances autonomous decision-making efficiency by 70%, and achieves 95% accuracy in cybersecurity threat detection, while maintaining up to 99% operational reliability in heterogeneous network environments. The findings confirm the feasibility of skyborne base station enabled telecommunication systems as a scalable solution for future integrated 5G/6G networks, enabling enhanced connectivity, improved network resilience, and efficient service delivery for next-generation digital applications</p>
