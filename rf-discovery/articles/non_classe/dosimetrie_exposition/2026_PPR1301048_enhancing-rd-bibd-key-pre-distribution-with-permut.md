# Enhancing RD-BIBD Key Pre-distribution with Permutation Aware Node Assignment in Fog Computing

*journal non renseigné — 2026*

## Résumé (texte d'origine)

<title>Abstract</title>  <p>Secure key management is a critical challenge in resource constrained, fog assisted IoT networks due to the high vulnerability of distributed nodes to physical capture attacks. Although combinatorial design based Key Pre-distribution Schemes (KPSs) provide deterministic key sharing and low overheads, their fixed block to node mapping makes them susceptible to systematic node capture attacks once the network topology is exposed. To address this vulnerability, this paper proposes a novel, secure, and hierarchical key pre-distribution scheme based on a combinatorial Residual Design (RD) integrated with a permutation aware key assignment mechanism. The proposed scheme constructs a hierarchical network topology using Balanced Incomplete Block Design (BIBD). To break the deterministic mapping between the combinatorial blocks and physical nodes, a randomized permutation function π is introduced at the base station prior to deployment. This mechanism hides the assignment mapping, increasing the adversary’s search space to m! (Where m is the number of blocks) and substantially enhancing resiliency against targeted node capture attacks without modifying the underlying structural parameters of the design. Analytical evaluations demonstrate that the proposed scheme achieves a network capacity of N nodes, requiring a maximum key chain length of only \(\:\sqrt[4]{\text{N}}\) keys per node. The scheme guarantees communication and computation overheads of O(q), which is highly compatible with resource constrained IoT devices. Furthermore, the local and global connectivity metrics remain unaffected by the permutation and is above 0.8, while the network resiliency is significantly improved. Finally, we show that the proposed scheme is independent of node mobility models, ensuring stable cryptographic performance in dynamic fog environments.</p>
