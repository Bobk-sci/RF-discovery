# Energy-Efficient IRS-Assisted Green Cellular Networks With Ground Base Station Sleep Mode

*journal non renseigné — 2026*

## Résumé (texte d'origine)

<title>Abstract</title>  <p>This paper investigates energy-efficiency maximization in an intelligent reflecting surface (IRS)-assisted aerial base station (ABS)-enabled cellular network with ground base station (GBS) sleep mode. The system adopts orthogonal resource allocation while explicitly considering co-channel interference among active transmitters.  The aerial base station provides flexible and adaptive coverage, complementing terrestrial infrastructure, while IRSs enhance signal propagation through controllable reflections. The phase shifts of IRS elements are jointly optimized with GBS activation, user association, transmit power allocation, and ABS positioning.  The resulting problem is formulated as a mixed-integer non-convex optimization problem under power, quality-of-service, and unit-modulus constraints. To efficiently address this challenge, a hybrid deep reinforcement learning framework is proposed, where Double Deep Q-Learning (DDQL) handles discrete decisions and Deep Deterministic Policy Gradient (DDPG) optimizes continuous variables.  The proposed approach significantly improves energy efficiency while maintaining reliable system performance.</p>
